## Домашнее задание 3

Реализовано ASP.NET Core MVC-приложение для варианта 17: справочник
`Издательства`, основная таблица `Журналы`, числовое поле `circulation_k`.
Доступ к SQLite выполняется через Entity Framework Core Code First, отчёты и
CRUD-операции построены на LINQ без прямых SQL-строк.

## Архитектура

- `Models` — entity-классы `Publisher` и `Magazine` с навигационными свойствами.
- `Data` — `AppDbContext` и первичное создание/заполнение базы через `EnsureCreated`.
- `Controllers` — CRUD для справочника и основной таблицы, отдельный контроллер отчётов.
- `ViewModels` — данные форм и отчёта без привязки Razor-страниц к лишним сущностям.
- `Views` — MVC-представления и общий layout с навигацией.

## Запуск

Приложение разработано на .NET 10 и использует современный `WebApplication` API.

```bash
cd ConsoleApp4/ConsoleApp4
dotnet run
```

По умолчанию приложение доступно по адресу `http://localhost:5000`.

### Запуск на произвольном порту

Вы можете указать любой порт при запуске:
```bash
dotnet run --urls http://127.0.0.1:5083
```

После запуска в консоли появится лог с подтверждением адреса:
`info: Microsoft.Hosting.Lifetime[14] Now listening on: http://127.0.0.1:5083`
